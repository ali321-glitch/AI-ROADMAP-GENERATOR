# AI-ROADMAP-GENERATOR# 🚀 AI Learning Roadmap Generator

A web application built with Python, Streamlit, and the Google Gemini API that instantly generates customized, step-by-step learning roadmaps tailored to any subject, experience level, and timeframe.

## ✨ Features
- **Customized Paths:** Adapts to Beginner, Intermediate, or Advanced skill tiers.
- **Flexible Timelines:** Tailors pacing based on your available time commitment.
- **Gemini Powered:** Leverages Google's fast text models for comprehensive technical outlines.
- **Export Ready:** Download your generated roadmaps instantly as Markdown files (`.md`).
